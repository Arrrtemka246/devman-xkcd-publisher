# Комиксы xkcd в Telegram

Скрипт скачивает случайный комикс xkcd и публикует его в Telegram-канал
вместе с заголовком, ссылкой на оригинал и авторским комментарием (`alt`).
После публикации временное изображение автоматически удаляется.
Один запуск — одна публикация. При ошибке программа завершается с ненулевым кодом.

Это решение урока «Публикуйте комиксы во Вконтакте» курса Devman.
В актуальном описании урока разрешена публикация в Telegram вместо VK,
поскольку описанный в уроке способ получения токена VK больше не работает.
Реализован разрешённый вариант с Telegram Bot API.

## Установка

Нужен Python 3.10 или новее. В папке проекта выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=@имя_канала
```

Получить токен бота можно у [BotFather](https://t.me/BotFather).
Добавьте своего бота в администраторы канала с правом публикации сообщений.
Для закрытого канала укажите числовой chat_id вместо `@имя_канала`.
Файл `.env` содержит секреты и исключён из Git.

Если подключение к Telegram требует прокси, дополнительно задайте `PROXY_URL`:

```dotenv
PROXY_URL=socks5h://127.0.0.1:1080
```

Прокси применяется только к запросам Telegram.

## Проверка доступа без публикации

```sh
python main.py --check
```

Программа проверит бота, канал и права публикации, ничего не отправляя.

## Публикация

Случайный комикс:

```sh
python main.py
```

Конкретный комикс, например комикс №353 про Python:

```sh
python main.py --comic 353
```

Комикс №404 исключён из случайного выбора: он намеренно отсутствует у xkcd.
Если авторский комментарий не помещается в подпись Telegram, он отправляется
целиком отдельными сообщениями. Автоматического повтора публикации при сетевой
ошибке нет: перед повторным запуском проверьте канал, чтобы не создать дубликат.

Можно использовать конфигурацию из другого локального файла:

```sh
python main.py --env-file /путь/к/настройкам.env
```

## Скачать без публикации

```sh
python main.py --comic 353 --download-only
python main.py --download-only --output-dir comics
```

Изображения сохраняются в `comics/` (или указанную папку) и не удаляются в этом
режиме. В терминал выводится авторский комментарий. Токен Telegram не требуется.
Изображения не входят в репозиторий.

## Проверки

```sh
python -m unittest -v
```

Проверяются исключение №404, сохранность длинных комментариев, очистка временных
файлов при ошибке публикации и отсутствие токена в сообщениях о сетевых ошибках.

## Устройство проекта

- `xkcd.py` — JSON API xkcd, выбор комикса и скачивание картинки.
- `telegram_api.py` — загрузка изображения и публикация комментария.
- `main.py` — аргументы командной строки, настройки и временные файлы.

Документация: [xkcd JSON API](https://xkcd.com/json.html),
